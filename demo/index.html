ghlike — demo & playground

Cada clic tarda ~8-12 s (el daemon abre tu navegador en segundo plano y pulsa el botón real con tu sesión). Las peticiones van en cola: si clicas varias, se hacen de una en una. El botón muestra su estado real después del primer clic.

Las 5 variantes — variant="…"

classic (por defecto)

pill

outline

glass (fondos con color o fotos)

block (llamada a la acción)

Personalización CSS — variables --ghlike-*

gh-like.mi-estilo {
  --ghlike-bg: #fff0f6; --ghlike-border: #ff2d87; --ghlike-fg: #c2185b;
  --ghlike-star: #ff2d87; --ghlike-radius: 4px; --ghlike-padding: 8px 16px;
}

¿A qué repo apunta? — gestión del target

El botón apunta al repo del atributo repo="owner/repo". Cámbialo en vivo (acepta también la URL completa de GitHub):

Caso de error — repo que no existe


El contador no carga (API 404) y al clicar verás "Repo not found".

Uso base: <gh-like repo="owner/repo"></gh-like>
