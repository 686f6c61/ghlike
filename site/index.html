Qué pasa cuando ejecutas ghlike owner/repo What happens when you run ghlike owner/repo

Nada de APIs ni de tokens: tu propio navegador pulsa el botón de Star por ti. Cuatro pasos, ~8–12 segundos. No APIs and no tokens: your own browser presses the Star button for you. Four steps, ~8–12 seconds.

  1. Encuentra tu sesión de github.com en un navegador Chromium de tu máquina (Brave, Chrome, Chromium, Edge, Vivaldi, Opera). Con --list puedes ver las sesiones detectadas. It finds your github.com session in a Chromium browser on your machine (Brave, Chrome, Chromium, Edge, Vivaldi, Opera). Use --list to see the detected sessions.
  2. Copia la tienda de cookies CIFRADA a un perfil desechable. Las cookies nunca se descifran: el fichero se copia tal cual, y el propio navegador lo abre con sus claves del sistema. It copies the ENCRYPTED cookie store to a throwaway profile. Cookies are never decrypted: the file is copied as-is, and the browser itself opens it with its system keys.
  3. Tu propio navegador pulsa el botón de Star real: arranca en headless, controlado por un pipe CDP privado (sin puerto TCP expuesto), abre el repo y hace clic en el botón — GitHub gestiona su propio CSRF. Luego verifica el nuevo estado. Your own browser presses the real Star button: it starts headless, driven over a private CDP pipe (no exposed TCP port), opens the repo and clicks the button — GitHub handles its own CSRF. Then it verifies the new state.
  4. Se cierra y limpia: el navegador se apaga y el perfil desechable se borra. Las cookies nunca se descifran ni salen de tu máquina. It closes and cleans up: the browser exits and the throwaway profile is deleted. Cookies are never decrypted and never leave your machine.
seguridadsecurity

Seguridad y privacidad Security & privacy

ghlike toca sesiones de navegador, así que el diseño entero está pensado para poder auditarse de un vistazo. ghlike touches browser sessions, so the whole design is built to be auditable at a glance.

Cero dependenciasZero dependencies

El cliente CDP es stdlib de Python y APIs nativas de Node, hablando con el navegador por un pipe privado. Sin cadena de suministro que auditar. The CDP client is Python stdlib and Node native APIs, talking to the browser over a private pipe. No supply chain to audit.

Código auditableAuditable code

~1.000 líneas por paquete, en un único fichero legible. Puedes leerlo entero antes de instalarlo. ~1,000 lines per package, in a single readable file. You can read it all before installing.

Las cookies nunca se descifranCookies are never decrypted

La tienda de cookies cifrada se copia a un perfil desechable; al acabar, el navegador se cierra y el perfil se borra. Nada sale de tu máquina. The encrypted cookie store is copied to a throwaway profile; when done, the browser is killed and the profile deleted. Nothing ever leaves your machine.

Sin tokens, sin OAuthNo tokens, no OAuth

Lo único que usa tu sesión es un clic en el botón de Star real — GitHub gestiona su propio CSRF. No hay credenciales que filtrar ni revocar. The only thing your session is ever used for is one click on the real Star button — GitHub handles its own CSRF. There are no credentials to leak or revoke.

limitacioneslimitations

Limitaciones conocidas Known limitations

  • Solo navegadores Chromium (Brave, Chrome, Chromium, Edge, Vivaldi, Opera): Firefox no implementa CDP. Chromium browsers only (Brave, Chrome, Chromium, Edge, Vivaldi, Opera): Firefox has no CDP.
  • ~8–12 s por operación: hay que arrancar el navegador, cargar el repo y pulsar el botón real. No es una API instantánea. ~8–12 s per operation: the browser has to start, load the repo and press the real button. It is not an instant API.
  • Depende del markup del botón de Star: si GitHub lo cambia, ghlike puede fallar hasta actualizar el selector (una línea). It depends on the Star button markup: if GitHub changes it, ghlike may fail until the selector is updated (one line).
